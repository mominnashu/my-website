# My Website

This repository contains a static website built as a single HTML file.

## Project overview

The site is designed as a personal webpage / portfolio-style landing page, and the main content is stored in:

- `Scam Shield_ is this link or message safe_ (2).html`

## How to view the site

Because this project is a static HTML page, you can either:

1. Open the HTML file directly in a browser, or
2. Serve the repo locally with a simple web server:

```bash
cd /path/to/my-website
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
